# 证据规则与复用记录

本项目把内容有据可查和择优复用放在制作全程。群公告转述老师提醒：资料有限、AI容易产生幻觉；论文、实验、产品和具体结论需要人工找到可靠来源复核。提醒来源见[课程要求](requirements.md)。

## 怎样核证

事实、数字、设备能力和图片回到原始来源，写清section、figure或table。实验要对应对象、人数、条件、对照、指标和结论范围。摘要、正文局部深读与全文取得分别记录，AI查阅与成员人工复核分别记录。

稿中每页的页脚、备注和[来源手册](../release/v3/来源手册.md)对应。解释性流程明确标作教学示意，原温度曲线保持原图性质；放松图按原表均值重绘，保留量表、组数、SD与检验记录。找不到依据时调整说法或换例，成员用[来源笔记](../references/source-note-template.md)补查即可。

打开关键原始来源，核对本组文字、图与结论，记录复核人和日期。公开论文入口受限时，可先在小群提供合法获取的材料与定位；原文再分发按许可证处理。原始缓存和其他课程私人预览保持在忽略目录，公开交付自己的分析、题录和已核许可素材。

## v3补证与择优复用

本轮复用已有广泛文献地图，定向核查实际进入主讲的解释，见[新增证据与入口实测](../research/2026-11-03-v3/README.md)。NIH/NIDCD与Columbia大学用于校准嗅觉通路，Malnic原始摘要用于组合响应；不把受体蛋白、神经元和脑区当同一对象。P05采用原图Fig.6d，不从柱高估数字。

A-Frame、WebXR与OSF资料比较后，主讲分享现成A-Frame场景与酒窖团队入口，WebXR留扩展。电脑原生渲染和键盘移动已实测，OSF主网页受限时通过官方API读取公开目录并取得有效使用手册；无需新建应用或采购硬件。

参考智能体V5和本轮独立审读，修改依据是内容归属、案例主次与图的理解缺口。口播去掉重复铺垫，把时间留给机制与实验解释。案例和讲法仍由各组精修，合稿按听众理解与真实证据判断。
