# 证据规则与择优复用

2026-10-28 确定：本项目特别重视“以无据断言为耻，以查证求实为荣”和“以闭门造轮为耻，以择优复用为荣”。老师提醒的来源层级见 [作业要求](requirements.md#群公告中的老师提醒与本轮补充)。

## 从选题到合稿持续查证

事实性表述、技术机制、数字、论文、产品能力、可用渠道、图片、视频与健康效果，都应有可追溯来源。自己的结构设计标明建议，解释与推断交代依据及边界，未来预测写出条件；不能把它们写成论文已经证明的结论。

优先采用原始论文和官方技术材料。综述用于形成知识地图和寻找原始研究；厂商资料可以证明厂商宣称什么，不能独自证明比较效果或健康收益。阅读程度及人工复核状态分别记录，AI 找到链接不等于人已复核。

每条具体表述至少记录：文稿位置、支持它的来源链接、原文页码／章节／图表、证据范围、限制、核查状态与人员。数字记录对象、样本或分母、对照、条件和单位；图示重绘也注明依据，不能无来源拼接后当作实验结果。采用 [来源笔记](../references/source-note-template.md)，无需让成员额外填写重复表格。

查证发生在选路线、写初稿、各组核改和最终合稿各阶段。无法访问或证据冲突时保留原话与缺口，降格表述、换案例或删除；不编造引用，不以“文末有参考文献”代替逐项对应。

## 宣传判断先查什么

- 究竟宣称产生了什么能力，演示过程与描述是否对应？
- 效果相对什么对照、用什么指标测量，有多少对象、哪些限制？
- 研究原型、可购买产品、可预约体验分别是什么状态，渠道是否仍有效？
- 是否从特定任务、短期体验或主观评分推到普遍能力或健康治疗？
- 不确定之处是什么，哪种新证据会改变本组判断？

这是本组拟采用的阅读框架，还没有对任何产品作出评价，也没有证明该框架的教学效果。

## 后续怎样继续择优复用

每当需要新案例、图示、技术解释或媒体，先找现有可靠材料和成熟方法，再比较是否服务听众目标。记录看过哪些候选、为什么采用、如何改编及使用条件；不复制未经理解的内容，不为显得新颖而增加额外实验或自制平台。只在现成材料确实不能解释问题时再自制，并说明必要性。
