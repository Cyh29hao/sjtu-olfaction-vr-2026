# 首稿制作约定

2026-11-01，依据用户最新生产授权与八项方向回答。目标是达到用户满意的智能体汇报准备水平，争取本次课程汇报的最好表现；具体名次取决于课堂呈现与教师评价。

- 采用蓝绿青春模板，以真实研究中的VR闻花演示贯穿。以一个应用展开“多了气味究竟帮了什么”，兼顾课程的科学与健康联系。
- 自然、有判断、偶尔轻松，结论由具体对象和证据支撑。以问题和画面帮助记忆，避免硬凑宣传式金句。
- 4人汇报，内容按12分钟内设计，另有2–3分钟问答。首稿无需真实器材，视频或静态连续画面可以辅助；媒体失败仍能完整讲。
- 比以往增加非文字表达：真实装置与任务截图、可编辑机制图、时序图、实验设计与结果图。投影负责让人看懂，口播负责解释。
- 第0组负责开场、收束、全场衔接与合稿；三个内容组分别核改原理、技术与应用。固定必要交接和时长，各组可自由换例、重写。组员可改文稿、提意见或交本组PPT副本，避免同时覆盖总稿。
- 发布总PPTX/PDF、口播、问答、来源手册、分组修改包及README。公开前检查来源共享范围、本机路径、中文编码、页面与口播一致及远端真实可读。
- 先产出完整候选，再从旁观者角度检查科学依据、叙事、语言、节奏、视觉和协作路径。发现具体问题就修复；自检与真人试讲、课堂验收分别记录。
- 本轮五小时起始剩余98%、周87%，警戒线10%。旧04:00–09:00计划已结束且保持停用；本轮无固定制作时段。额度接近警戒线时保存实际候选和精确待办，若需要续作则另核可用调度与实时重置时间。
