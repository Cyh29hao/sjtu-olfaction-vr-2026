# 小组工作过程

上海交通大学《气味科学中的健康密码》小组汇报 · 气味、VR与虚拟感官

## 分工与交接

| 组别 | 实际承担的内容 | 交给下一段的内容 |
| --- | --- | --- |
| 第 0 组 · 总体整合 | 陈云海统筹分工、确定主线与版式，整合并审阅 PPT 与讲稿，负责开场与收束。 | 用开场闻花动作串起理论、装置和应用，统一换页、时长与答辩入口。 |
| 第 1 组 · 科学原理 | 朱轶宸负责嗅觉数字化的难点、汇总组稿并参与合稿修改，刘昌镇整理嗅觉产生原理，潘力熔整理气味分子原理。 | 由分子传输和受体响应提出装置应满足的条件。 |
| 第 2 组 · 装置实现 | 蔡天怿组织组内修订并负责 T03，娄嘉恒负责 T02，王叶负责 T01，分别核查材料、改写口播并试讲。 | 说明可控释香的实际能力和条件，把问题转交给应用组的实验比较。 |
| 第 3 组 · 应用与意义 | 陈柔羽统筹修订并完成讲稿，杨绎麟、邓沐熙、隋沅辰修改 PPT、搜集并核对资料。 | 分辨辨香任务难度、主观在场感与额外放松收益各自能得到什么结论。 |

主讲为陈云海、朱轶宸、蔡天怿、陈柔羽。答辩的跨段问题由总组长串联，各段发言人准备本段原理、装置或实验细节。个人贡献的来源及确认记录见[成员与分工](team.md#实际贡献记录)。

## 微信和 GitHub 各承担什么

- 微信用于分组沟通、确认分工、讨论跨段衔接和反馈具体改法。
- GitHub 保存各组稿件、来源和整合版本。组稿可以直接提交、通过 PR 汇总，或交由整合者纳入总稿。首页提供各组文件及最新版入口。
- 修改意见尽量带页码、原句或图号。整合后同步页面、口播和来源，便于下一位发言人按同一版本准备。
- [来源手册](../release/v4/来源手册.md)按页提供文献与定位。可以从[整场走稿](当前审阅与走稿.md)了解各段怎样交接与留时。
