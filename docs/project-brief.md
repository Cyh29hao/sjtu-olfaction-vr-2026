# 项目方向与 v2 协作初稿

更新：2026-11-03。采用已确认的闻花叙事、蓝绿青春模板与四人讲述安排。当前协作入口以 [仓库首页](../README.md) 和 v2 为准，v1 保留供比较。

## 希望听众带走什么

同学能大致说清虚拟嗅觉怎样工作，举出一种具体应用，并会追问宣传的比较对象和实际结果。认真听的同学还能解释材料、触发与退味怎样配合，理解应用前景取决于哪些条件。教师关心的科学依据与实际意义，贯穿机制、装置、实验和结论。

## 一次完整体验，再看两种任务

开场使用真实研究中的 VR 闻花演示。科学组先说明鼻子接收气味分子、受体响应具有组合特点；落实到这次体验，需要预装合适材料并控制释放。技术组接着讲同一套近鼻装置：材料和加热元件放在哪里，靠近动作怎样触发指令，停止后余味为什么仍要散去。

应用组先进入虚拟酒窖。辨香本身就是练习内容，装置与场景一起组织嗅闻、作答和反馈。随后明确换到放松目标：这时关心的是加香相对同样程序的无香条件，多带来多少变化。讲清对照与结果，再讨论怎样使用和判断宣传。

AI 根据分子预测气味、不同装置形态的比较移入备课。它们可以回答追问，主讲不再分出另一条技术支线。

## 页面与节奏

| 内容 | 模块 | 口播设计预算 |
| --- | --- | --- |
| 开场与收束 | O01–O02、C01–C02 | 2分30秒 |
| 科学原理 | S01–S03 | 2分15秒 |
| 技术与设备 | T01–T03 | 2分40秒 |
| 多感官与应用 | A01–A04 | 3分20秒 |

主讲共 14 页，内容预算 645 秒；另留 75 秒换人、指图和停顿，总预算 12 分钟，问答另计 2–3 分钟。以上是设计预算，真实主讲者计时后再调整。另有 7 页备课／参考，完整文件最后一页为 11 人分工。

静态图即可讲完，现场闻香与视频不作为必要条件。讲图时给听众认对象、看坐标和理解比较的时间。时间紧时先压缩举例与前景，保留完整实现链、放松研究的对照和结果，以及换人前后的交接。

## 整体性与协作自由

第 0 组负责开场、收束、合稿与视觉。第一组维护 S 模块，第二组维护 T 模块，第三组维护 A 模块。共同维护中心问题、必要交接、术语和全场时长，各组可换例、补证与重写；改到相邻部分时说明影响。

组员可直接改本组文稿、提交意见，或交回本组 PPT 副本与对应口播、来源。整合者同步内容源，统一更新各组和全场版本。无需每人安装工具，详见 [协作与合稿](协作合稿.md)。

## 使用与确认

[仓库首页](../README.md)提供投影、口播、备课与各组入口。[v2来源手册](../release/v2/来源手册.md)逐页对应原始来源，[广泛文献地图](../research/2026-11-01/论文综览.md)保留不同阅读深度。

本稿是供小组精修的完整候选。成员人工复核、四人真人计时、教室放映与 Canvas 提交由后续协作完成。每人至少一项实际贡献，最终提交前逐人填写确认，尚未完成的工作保持待办。
