# 项目方向与 v3 协作初稿

更新：2026-11-19。采用三章结构、蓝绿青春视觉和四人讲述。初稿用于统一方向并交给各组精修，具体讲法仍可调整。[叙事与合稿基准](叙事与合稿基准.md)记录已确认的方向与判断方法。

## 希望听众带走什么

同学能解释虚拟嗅觉怎样把真实气味接进VR，并举出它已能支持的交互任务和一个在场感实验。辨香训练与额外放松收益仍需专门验证。机制、工程和实验结果共同回答虚拟嗅觉现在适合做什么。

## 三章怎样推进

开场O01用40秒，按“引入→点击播放16.6秒无声闻花短片→点题→切目录”讲述。O02用15秒交代理论、装置、应用与意义。T02用同一演示的静态三帧解释控制链，应用段进入新任务时说明为什么选择它。

| 章节 | 本稿展开什么 | 接下来要回答什么 |
| --- | --- | --- |
| 嗅觉感知的科学基础 | 气味分子、受体与神经信号，受体的组合响应 | 装置怎样提供并控制合适的刺激？ |
| 虚拟嗅觉的技术实现 | 认清一套近鼻装置，跟随动作触发释香，再看停止与切换；T04提出应用问题 | 人能不能凭气味答题、觉得更在场或额外放松？ |
| 应用与意义 | 酒窖辨香任务及难度，场景加香对在场感的影响，放松对照 | 哪些用途已有证据，哪些仍需验证？ |

应用小结交给分工展示，再用答辩总图串起三章。停在总图，按需从内容标题进入正文和备课。

技术主讲聚焦一套近鼻装置。应用分别讲气味怎样成为辨香任务的线索、怎样影响主观在场感，以及加入同一放松程序是否带来额外收益。分子预测与装置形态比较留在备课。

## 整体性与协作自由

三个内容组各自维护连续段落，第0组负责开场、分工展示、答辩收束、全场衔接与视觉。各组可换例、改图、补证和重写；影响相邻部分时说明交接与用时，整合者一起调整。

合稿时检查：只看目录与标题能否理解推进；上一段问题是否被下一段接住；案例作用是否清楚；结论是否对应原始测量；四个人是否能从容守时。它们约束最终效果，不要求照抄初稿的句子、页数或版式。

组员可改本组文稿、填写建议，或交本组PPT副本及对应口播和来源。第0组把确认的内容合入总稿，详见 [协作办法](协作合稿.md)。
