# 项目方向与 v3 协作初稿

更新：2026-11-03。采用四章结构、蓝绿青春视觉和四人讲述。初稿用于统一方向并交给各组精修，具体讲法仍可调整。[叙事与合稿基准](叙事与合稿基准.md)记录已确认的方向与判断方法。

## 希望听众带走什么

同学能大致解释虚拟嗅觉，举出一种了解、体验或使用方式，并知道怎样查宣传中的用途和效果。认真听的同学还能理解基本实现及值得继续研究的方向。机制、工程依据和实验结果要服务这些理解目标。

## 四章怎样推进

开场用约一分钟说明动机、概念与路线。闻花用于引入和装置解释；应用段进入新任务时，说明为什么选择它。

| 章节 | 本稿展开什么 | 接下来要回答什么 |
| --- | --- | --- |
| 嗅觉感知的科学基础 | 气味分子、受体与神经信号，受体的组合响应 | 装置怎样提供并控制合适的刺激？ |
| 虚拟嗅觉的技术实现 | 认清一套近鼻装置，跟随动作触发释香，再看停止与切换 | 这样的能力适合什么具体任务？ |
| 应用场景与实验结果 | 展开酒窖辨香任务及混合难度结果，2016年放松实验作短对照 | 自己怎样尝试，怎样理解效果宣传？ |
| 体验途径与效果判断 | 笔记本／手机的了解入口，研究团队开放项目与使用条件，宣传判断 | 回答开场问题，并给出有依据的前景 |

一个主要装置和一个主要应用留出展开时间。分子预测、装置形态比较等次要材料保留在备课，需要时回答追问。放松实验用于说明用途变化后应该测什么收益，健康联系是代表应用之一。

## 整体性与协作自由

三个内容组各自维护连续段落，第0组负责开场、第四章、全场衔接与视觉。各组可换例、改图、补证和重写；影响相邻部分时说明交接与用时，整合者一起调整。

合稿时检查：只看目录与标题能否理解推进；上一段问题是否被下一段接住；案例作用是否清楚；结论是否对应原始测量；四个人是否能从容守时。它们约束最终效果，不要求照抄初稿的句子、页数或版式。

组员可改本组文稿、填写建议，或交本组PPT副本及对应口播和来源。第0组把确认的内容合入总稿，详见 [协作办法](协作合稿.md)。
