# 项目方向与首稿

更新：2026-11-01。以用户本次完整制作、四人讲述和公开发布授权为准。先前仅调研／暂不制作PPT的安排已被覆盖；旧夜间调度保持停用。

## 希望听众带走什么

同学能说清虚拟嗅觉大致怎样工作，举出一个真实应用，并能追问宣传背后的对照和结果。认真听的同学还能解释释放、同步与退味的难点，理解有条件的前景。教师关心的科学依据与实际意义，贯穿机制、实验和结论。

## 全场怎样连起来

从VR闻花的真实演示出发，科学组解释鼻子需要怎样的刺激，技术组解释材料与装置怎样配合场景，应用组接着看虚拟酒窖的辨香任务和一项放松对照研究，最后回到“这股香，多帮了多少”。选用蓝绿青春模板。讲述自然、少术语堆积，更多使用真实图、可编辑机制和实验图。

首稿16页主讲，随后5页参考／备课，物理最后一页为11人分工。按四位发言人设计，内容预算660秒，另留60秒换人和停顿；问答另计2–3分钟。无需真实器材，静态图即可完整讲述。

## 整体性与协作自由

第0组负责开场、收束、合稿与视觉。第一组维护S模块，第二组维护T模块，第三组维护A模块。共同维护中心问题、跨组交接、术语和时长，各组可换例、补证与重写；改到相邻部分时说明影响。

组员可直接改本组文稿、提交意见，或交回本组PPT副本与对应口播／来源。整合者同步内容源、统一生成总稿，避免同时覆盖总PPTX。无需每人安装工具。详见[协作合稿](协作合稿.md)。

## 首稿交付入口

[总览README](../README.md)提供投影、口播、备课与各组入口。[来源手册](../release/v1/来源手册.md)逐页对应原始来源。[广泛文献](../research/2026-11-01/论文综览.md)保留不同阅读深度，核心深读见同目录deep-review。

本稿是供小组精修的完整候选。组员人工复核、四人真人计时、教室放映与Canvas提交由后续协作完成。每人至少一项实际贡献，最终提交前逐人填写；尚未做过的工作留空。
