# 第三组：当气味进入虚拟感官系统

组长：陈柔羽。成员：陈柔羽、杨绎麟、邓沐熙、隋沅辰。依据为 2026-10-29 最新名单，邓沐熙已从第 0 组调整至本组。发言人由组内安排，不自动由组长担任。

## 待研究的问题

- 气味与视觉、听觉、触觉的融合怎样被研究和测量？
- 沉浸感、情绪、记忆、行为和健康分别有什么证据，能否区分？
- 医疗、训练、心理、娱乐等场景中，哪些少量案例最能承接前两组？
- 哪些结论只适用于特定样本或任务，哪些仍是设想？

这些方向不要求全部覆盖。选择能支撑主线的案例，避免把应用名单当作证据。

## 启动后怎样推进

启动前由组长建小群，组内推选一位 GitHub 代表提供账号。约 11 月 10 日启动后，组长带头组织本组第一轮内容；陈云海的 demo 只作参考，可以删除不成立的结论、换例、补证和重写。本组核实体验与应用研究，解释效果如何测量、支持到哪一步，帮助形成有依据的宣传判断并收束全场。每个人至少有一项实际贡献；工作量与协作形式自行安排，有比赛或其他时间困难及时在组内沟通。当前没有已核实的健康结论。

使用 [来源笔记模板](../../references/source-note-template.md)，写明对象、样本、对照、测量指标和限制；相关性、短期实验效果与临床效果不能混写。不预设所有应用都属于炒作，也不把证据不足直接写成诈骗。时间按全场内容重定。
