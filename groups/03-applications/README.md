## 第一轮先改什么

检查案例能否服务普通同学理解，写清对象、样本、对照和测量。区分体验评分、任务结果、短期生理变化与临床效果，精选研究，避免应用名单。

本组负责精选效果研究、健康相关证据与适用边界。接到第二组的装置能力，用具体对照研究回答价值问题，再交给全场收束。 内容、案例、图示和口播都可以改；若改变“效果证据与宣传判断”的交接意思，交稿时说清影响，让相邻组和第 0 组一起调整。

先改 `本组文稿.md` 或把意见写进 `建议.md`，无需理解代码。也可以直接改本组 PPTX 副本，连同对应口播、来源一起交回。整合者负责同步 `content.json`，统一更新本组与全场版本，避免下一次生成时丢失大家的修改。

## 组内怎样分

组长建小群、带头组织第一轮修改；组内推选一位 GitHub 代表，最好就是组长，把账号发给陈云海核对并邀请。每个人至少完成一项实际工作，工作量、协作形式和发言人自行安排。可以核源、改解释、做图、改页或试讲，不机械拆成互不交流的岗位。

来源核查使用 [来源笔记模板](../../references/source-note-template.md)，写具体原文位置、支持的表述和实际阅读范围。AI 检查与人工复核分别记录。最后由各位在 [贡献表](../../docs/team.md#实际贡献记录) 确认自己的工作。
