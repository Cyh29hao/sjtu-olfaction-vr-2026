## 第一轮怎样精修

酒窖展示气味可以成为交互任务所需的信息，Fig.6d保留原图及SD，正文直接比较同为三味的第3级和第4级。P35比较同一场景两轮加香与撤香的在场感，P15比较相同触觉条件下加香的额外放松收益。三项研究的对象、条件和指标各有区别。

各组可以继续改讲法、图示或证据。换案例时说明它承担的作用，以及A05和末页QA可以据此作什么判断。合并时检查问题衔接、图表读法、测量与结论，以及四人能否顺畅守时。

先改本组文稿或写建议，也可以交本组PPTX副本及对应口播、来源。跨组变化连同交接和用时一起说明。第0组把确认的内容合入总稿，组员无需安装工具或理解JSON。
