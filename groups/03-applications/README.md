# 第三组：当气味进入虚拟感官系统

成员：陈柔羽、杨绎麟、隋沅辰。最后一版接龙中三人均未表示愿意担任组长，负责人及主讲待协商。

## 待研究的问题

- 气味与视觉、听觉、触觉的融合怎样被研究和测量？
- 沉浸感、情绪、记忆、行为和健康分别有什么证据，能否区分？
- 医疗、训练、心理、娱乐等场景中，哪些少量案例最能承接前两组？
- 哪些结论只适用于特定样本或任务，哪些仍是设想？

这些方向不要求全部覆盖。选择能支撑主线的案例，避免把应用名单当作证据。

## 第一份小交付

一页提纲、少量候选来源、一个拟讲研究的设计与结果梳理，以及回到全场中心问题的结尾。当前没有已核实的健康结论。

使用 [来源笔记模板](../../references/source-note-template.md)，写明对象、样本、对照、测量指标和限制；相关性、短期实验效果与临床效果不能混写。约 3 分 30 秒仅为讨论草案。
