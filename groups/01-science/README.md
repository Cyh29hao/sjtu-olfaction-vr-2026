# 第一组：气味与嗅觉的科学原理

成员：刘昌镇、潘力熔、朱轶宸。朱轶宸在接龙中愿意当组长，正式角色待确认。

## 待研究的问题

- 从气味分子到嗅觉感知，可以用怎样的通俗机制图说明？
- 气味的描述、编码、数字化和复现分别涉及什么问题？
- 哪些已核实的科学限制会成为第二组的设备设计需求？

这些是问题清单，不代表已经得出结论。先查核心原理，在有限时段内解释理解技术所需的科学基础，避免堆积术语。

## 接到统一初稿后怎样精修

先由陈云海与 AI 形成全场稿，本组核实基础原理、机制图和术语，删掉理解技术不需要的细节，检查向第二组交接是否自然。可以补证、换例和重写；不要求重新从空白做一套内容。接稿前也可补充问题和候选来源。

本组要帮助听众看懂虚拟嗅觉所需的科学基础，并判断哪些表述超出了证据。后续完整分工和听众目标见 [项目方向](../../docs/project-brief.md)；约 3 分钟只是旧草案，时间按全场内容重定。

资料统一使用 [来源笔记模板](../../references/source-note-template.md)；说明读到了摘要还是原文。三人共同打磨内容，不机械分成互不交叉的岗位。
