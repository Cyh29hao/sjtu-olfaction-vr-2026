# 第二组：气味如何被做进虚拟世界

成员：娄嘉恒、王叶、蔡天怿。蔡天怿在接龙中愿意当组长，正式角色待确认。

## 待研究的问题

- 怎样生成、储存、释放、传输、切换和清除气味？
- 怎样与 VR 场景同步，怎样描述延迟、残留或切换等指标？
- 哪些研究装置或产品适合做代表案例？它们实际验证了什么，还没验证什么？
- 怎样将技术能力交接给第三组的应用分析？

先理解流程，再选少量有依据的案例；此处尚未核实任何设备或产品。研究原型、演示装置和商业产品分开描述，厂商宣传不能替代效果研究。

## 第一份小交付

一页技术流程提纲、少量候选来源、一个有原始资料的案例候选，以及向第三组交接的一段话。数字与功能需标注出处及条件，不能先写参数再找来源。
