## 第一轮怎样精修

让听众先认清近鼻装置，再追踪一次动作、指令与释放，最后解释停止和切换。闻花在这里帮助解释装置；分子预测与形态比较可留给备课。

装置说明、流程图、难点与工程证据均可改。与第一组接好呈现要求，再把可用能力交给应用组。合并时一起看目录和标题能否说明推进，前后问题是否被接住，案例作用是否清楚，结论是否对应测量，四个人能否顺畅守时。

先改本组文稿或写建议，也可以交本组PPTX副本及对应口播、来源。跨组变化连同交接和用时一起说明。第0组把确认的内容合入总稿，组员无需安装工具或理解JSON。

## 组内安排

组长建小群并组织第一轮工作，组内推选一位GitHub代表，把账号交陈云海核对并邀请。每人至少完成一项实际工作，工作量、协作形式和发言人自行安排。

来源核查用 [来源笔记模板](../../references/source-note-template.md)，记录原文位置、支持的表述与实际阅读范围。AI检查和人工复核分开，实际贡献由本人在 [贡献表](../../docs/team.md#实际贡献记录) 确认。
