# 第二组：气味如何被做进虚拟世界

组长：蔡天怿。成员：娄嘉恒、王叶、蔡天怿。依据为 2026-10-29 最新名单。

## 待研究的问题

- 怎样生成、储存、释放、传输、切换和清除气味？
- 怎样与 VR 场景同步，怎样描述延迟、残留或切换等指标？
- 哪些研究装置或产品适合做代表案例？它们实际验证了什么，还没验证什么？
- 怎样将技术能力交接给第三组的应用分析？

先理解流程，再选少量有依据的案例；此处尚未核实任何设备或产品。研究原型、演示装置和商业产品分开描述，厂商宣传不能替代效果研究。

## 启动后怎样推进

启动前由组长建小群，组内推选一位 GitHub 代表提供账号。约 11 月 10 日启动后，组长带头组织本组第一轮内容；陈云海的 demo 只作参考，内容和形式均可改。本组核实实现流程、设备案例与参数，给出真实且说明条件的体验或应用方式，检查向第三组的交接。每个人至少有一项实际贡献；工作量、协作形式和发言人由组内安排。

本组重点让听众能说出“它是什么、怎样实现、怎样接触”，并用设备实际能力检查宣传。渠道可用性要记录查询日期；原型不能自动写成可购买产品，厂商宣传不能替代效果证据。
