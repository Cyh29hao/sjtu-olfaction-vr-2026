## 整合时看什么

先看 [合稿基准](../../docs/叙事与合稿基准.md#合并时用这些问题检阅)：目录与标题是否讲得清推进，前后问题是否承接，每个案例是否有明确作用，结论是否对应测量，四人是否顺畅守时。

具体到本稿，科学组连续讲基础再交呈现要求，技术组讲透一个装置，应用组展开酒窖任务与混合难度结果，并用放松实验作短对照。闻花用于引入和装置解释，应用有自己的任务对象。

各组可提出更好的案例、图示和讲法。整合时保留原稿，确认影响，再统一更新页面、口播和来源；总稿采用什么，以理解、证据和讲述效果判断。

## 个人入口与课堂确认

说明网页能观看还是能操作，哪些完整功能需要额外嗅觉硬件；按手机、笔记本与教室播放条件检查。静态图可独立讲完，实际示意由组内按已有条件决定。

请各组确认内容和交接，再由真实主讲者试讲、找未参与制作的同学复述。成员亲自复核、真人计时、贡献和Canvas提交在实际完成后记录。最后一页最终换成每个人已完成并确认的具体工作。
