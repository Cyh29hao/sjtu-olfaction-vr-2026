## 合稿时优先看

1. S03提出的材料和释放要求，是否被T01–T03的完整流程接住。
2. T03从连续嗅闻的难点，是否自然转到A01的具体练习。
3. A01换到A02时，是否让听众知道目标从辨香变成放松；A03的比较是否回答加香的额外作用。
4. C01能否让听众把比较对象、测量结果和使用条件用到一句具体宣传上。

各组可以换例、补证和重写。先看修改影响什么，再与相邻组协调；统一版式和转场，保留原稿，把文稿或PPT改动同步进内容源。各组不必一起编辑总PPTX。

## 成稿与课堂确认

逐页看实际画面，核对口播与来源；请各组确认意思和承接。之后由真实主讲者完整试讲，找未参与制作的同学复述。人工复核、真人试讲、实际贡献和Canvas提交分别记录，尚未完成的保持待办。

初稿末页列已知组别和组织职责；最终提交前改成每个人已完成并确认的具体工作。
