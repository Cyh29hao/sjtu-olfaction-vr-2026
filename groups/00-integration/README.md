## 第 0 组负责的判断

1. 开场提出的问题，后面是否真的回答；花园故事和真实论文实验是否区分清楚。
2. 科学难点是否变成设备需求，设备能力是否接上实际效果；删掉跨组重复，补齐省略的前提。
3. 各组改稿是否改变相邻术语、结论或用时；内容源、总 PPT、口播和引用是否同步。
4. 全场是否能在 12 分钟内讲清，最多 4 人上台，另留 2–3 分钟互动。

各组先读、先改本组文稿，也可以交本组 PPTX 副本。整合时先保留原稿与修改记录，再将确认的改动同步进内容源，统一生成各组和全场版本。总稿不强行保留首稿中的案例或句子。

## 发布前与课堂前

逐页看真实渲染，核对口播、来源和问答。请各组确认意思与转场；再由真实主讲者完整试讲，找未参与制作的同学复述。人工复核、真人试讲、最终贡献确认和 Canvas 提交分别记录，未做的保持待办。

初稿最后一页应列已知组别和组织职责，实际贡献待成员填写确认；最终提交前换成每个人已经完成的具体工作。
