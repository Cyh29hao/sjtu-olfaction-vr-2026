# v2 改了什么

2026-11-03。v1保留在[原版本目录](../v1/)，v2是供各组继续精修的协作稿。

v1已经准备了装置、实验和来源，但主讲在气味编码、AI预测、设备比较与应用之间换得较快。这一版保留可靠素材，集中把讲述顺序和看图方式改清楚。

## 主讲沿一条问题往下走

1. 从真实的VR闻花演示出发，问鼻子需要收到什么。
2. 解释气味分子和受体组合，再落到选材料、调释放、配合动作。
3. 技术段沿一套近鼻装置，把储香、加热、动作触发与余味散去讲完整。
4. 从一次受控嗅闻走到酒窖辨香：气味成为题目，场景组织动作和反馈。
5. 明确换到放松时目标不同，再介绍四组对照和结果。
6. 最后用一个宣传例子做短练习，回到实现、具体用途与后续进展。

主讲由16页调整为14页。AI预测和装置形态比较移到备课，完整PPT仍有22页，最后一页保留11人分工。内容设计645秒，另留75秒用于换人、指图与停顿，问答另计2–3分钟。

## 图、口播与判断一起改

- 原来较复杂的装置拼图，在主讲中改为近鼻实物配工作部件说明；完整形态比较留备课。
- 温度曲线保留原图含义，用它解释加热与冷却；气味散去另结合材料、气流与距离讲解。
- 放松实验明确使用投影房间、薰衣草气味和人造草触觉，四组表先交代各项刺激。
- 结果图直接标明“无／有触觉、无香／加香”，口播指明左边两组和右边两组怎样比较。均值来自原表，作者的统计结论与图上高低分别解释。
- 结尾直接交代已经实现的辨香任务、这次放松研究的结果及值得继续改进的环节，减少重复的审稿式提醒。

## 各组怎样继续

科学组负责S01–S03，技术组负责T01–T03，应用组负责A01–A04；第0组维护开场与收束。各组可以换例、重写和补证，涉及前后段问题、术语或时长时一并说明。

各组文稿、PPT副本与来源均从同一内容源同步，交回修改时同时带上口播和来源。真人试讲、成员人工核源及具体贡献记录仍由后续组内协作完成，见[验收与试讲](验收说明.md)。
