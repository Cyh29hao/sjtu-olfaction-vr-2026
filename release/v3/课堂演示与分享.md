# 课堂演示与课后分享

主讲以静态页面即可讲完。第12页提供两个与虚拟嗅觉直接相关的入口：

- [酒窖研究团队介绍](https://www.su.se/english/news/articles/2022-10-12-smelling-in-vr-environment-possible-with-new-gaming-technology)：任务介绍、演示和公开制作资料。2026-11-17重新查看了团队网页；实际嗅闻需要对应装置、材料及内容。
- [下载闻花演示短片](../../assets/v3/flower-demo.mp4)：约16.6秒，来自Liu等2023年论文补充视频3。右侧二维码指向仓库的短片下载，课后可打开；手机扫码与下载体验待实机确认。

短片为1920×1080、H264、无声，出处和CC BY 4.0署名见[媒体记录](../../assets/v3/media-credits.json)。有既有解码与关键帧检查记录，尚未在教室电脑或PowerPoint放映中实播。它没有嵌入PPTX；如采用，提前下载试播，并计入T02的55秒预算。静态三帧也可完成讲述。

影片展示研究装置的动作配合，不是本组自做的实验。原始补充视频直链本轮访问遇到TLS错误，故课堂二维码使用已保存、可随仓库下载的短片。

A-Frame普通浏览器场景已移出主讲，因为它不提供嗅觉。旧入口检查保留为历史记录，见[2026-11-03检查](../../research/2026-11-03-v3/入口检查.json)，不能当作本轮手机或教室实测。
